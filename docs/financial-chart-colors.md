## Chart Design Guidelines

### 1. Series Hierarchy

| Priority | Color | Role |
|----------|-------|------|
| **Primary** | Revenue Blue `#2563EB` | The headline metric—always first in legend, always most prominent |
| **Secondary** | Expenses Teal `#0D9488` | The context metric—comparison counterpart to primary |
| **Outcome** | Profit Emerald / Loss Crimson | The result metric—appears last, summarizes the story |
| **Reference** | Benchmark Gray `#A1A1AA` | The background—never competes for attention |
| **Generated** | Forecast Fuchsia / AI Insights Fuchsia | The intelligence layer—always marked as such |
| **Structural** | Assets Blue / Liabilities Amber | Balance sheet elements—share hues with income statement for continuity |
| **Qualitative** | Risk Crimson / Opportunity Emerald | Forward-looking assessments—use existing semantic colors |

**Rule:** Maximum 8 series in a single chart. Beyond 8, aggregate into "Other" category with muted treatment.

---

### 2. Color Assignment Logic

| Chart Type | Primary Color | Secondary Color | Tertiary Color |
|------------|---------------|-----------------|----------------|
| Income Statement | Revenue Blue | Expenses Teal | Profit Emerald |
| Balance Sheet | Assets Blue | Liabilities Amber | Equity Emerald |
| Cash Flow | Operating Blue | Investing Teal | Financing Crimson |
| Forecast Chart | Actuals Blue | Forecast Fuchsia | Confidence band (lighter Fuchsia) |
| Risk Dashboard | Exposure Amber | Risk Crimson | Mitigation Emerald |
| Peer Comparison | Company Blue | Peer Teal | Benchmark Gray |
| AI Analytics | Actuals Blue | AI Insights Fuchsia | Trend Blue (heavier stroke) |

---

### 3. Visual Hierarchy Rules

- **Stroke weight:** Primary series = 2px, Secondary = 1.5px, Tertiary/Reference = 1px
- **Opacity:** Actuals = 100%, Forecast = 80%, Benchmark = 40%
- **Fill:** Area charts use primary color at 10% opacity; never exceed 15% opacity for fills
- **Markers:** Actual data points use 4px circles; forecast uses 4px diamonds; benchmark uses 2px circles
- **Grid lines:** Always neutral-200 (#E4E4E7) light / neutral-700 (#3F3F46) dark at 1px
- **Axes:** Text in neutral-500 (#71717A) for light / neutral-400 (#A1A1AA) for dark

---

### 4. Combination Rules

| Combination | Allowed | Notes |
|-------------|---------|-------|
| Revenue + Expenses + Profit | ✅ | Core income statement trio |
| Assets + Liabilities + Equity | ✅ | Core balance sheet trio |
| Actuals + Forecast + Benchmark | ✅ | Standard time-series with context |
| Revenue + Expenses + AI Insights | ✅ | AI overlay on standard chart |
| All 8 standard series | ⚠️ | Maximum; requires careful ordering |
| Revenue + Profit + Loss + Risk | ❌ | Too many outcome colors; aggregate Loss and Risk |
| Forecast + AI Insights | ❌ | Fuchsia on fuchsia; use Forecast for projection, AI Insights for annotations only |

## Accessibility Rules

### WCAG 2.1 AA Requirements

| Requirement | Standard | Chart Application |
|-------------|----------|-------------------|
| **Normal text contrast** | 4.5:1 minimum | All axis labels, legend text, data labels |
| **Large text contrast** | 3:1 minimum | Chart titles, section headers |
| **Color independence** | Information not conveyed by color alone | All series paired with line style (solid/dashed/dotted) or marker shape (circle/square/diamond) |
| **Focus indicator** | 3:1 against adjacent | Chart tooltips and hover states |
| **Colorblind safety** | Pass deuteranopia, protanopia, tritanopia | All color combinations verified |

### Colorblind Safety Matrix

| Combination | Deuteranopia | Protanopia | Tritanopia | Safe? |
|-------------|--------------|------------|------------|-------|
| Revenue Blue + Expenses Teal | ✅ Distinct | ✅ Distinct | ✅ Distinct | Yes |
| Profit Emerald + Loss Crimson | ✅ Distinct | ✅ Distinct | ✅ Distinct | Yes |
| Forecast Fuchsia + AI Insights Fuchsia | ❌ Same hue | ❌ Same hue | ❌ Same hue | No — never use together |
| Assets Blue + Liabilities Amber | ✅ Distinct | ✅ Distinct | ✅ Distinct | Yes |
| Benchmark Gray + any series | ✅ Distinct | ✅ Distinct | ✅ Distinct | Yes |
| Risk Crimson + Opportunity Emerald | ✅ Distinct | ✅ Distinct | ⚠️ Similar | Yes (with symbol differentiation) |

**Rule:** Never place Forecast Fuchsia and AI Insights Fuchsia on the same chart without shape differentiation (diamond vs circle) and explicit labeling.

### Pattern Fill Requirements

For colorblind users and print/grayscale contexts:
- **Negative values:** Diagonal stripe pattern (45°) in addition to crimson fill
- **Forecast values:** Dotted line in addition to fuchsia color
- **Benchmark values:** Dashed line in addition to gray color
- **AI-generated values:** Diamond markers in addition to fuchsia color

### Text Label Requirements

| Element | Minimum Contrast | Font Size | Weight |
|---------|-----------------|-----------|--------|
| Chart title | 4.5:1 | 16px | 600 |
| Axis labels | 4.5:1 | 12px | 400 |
| Legend text | 4.5:1 | 12px | 500 |
| Data labels | 4.5:1 | 11px | 500 |
| Tooltip text | 4.5:1 | 13px | 400 |

## Summary

The Financial Chart Color System provides 13 semantically meaningful colors, each with explicit HEX values, usage guidelines, and accessibility validation. The system maintains consistency with the broader Analytix brand palette while introducing finance-specific logic: revenue = primary blue, expenses = analytical teal, profit/loss = emerald/crimson, forecasts = fuchsia, and structural elements = balance sheet-specific colors (blue/amber/emerald).

All chart colors are colorblind-safe, WCAG 2.1 AA compliant, and designed for maximum information density without visual fatigue. The system scales from 16px favicon-level data viz to 10-foot conference presentations.
